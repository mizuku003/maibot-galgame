# galgame领域大神（MaiBot 插件）

聚合查询 galgame 的中文名、汉化状态、通关时长、标签、评分与玩家评价，并查看 gal 圈动态。

**不知道怎么用就先打 `/gal help`** —— 它会发一张用法卡，所有指令和写法都在上面。

---

## 注意事项

- ⚠️ **批评空间（EGS）是可选源，但代理要求很严：基本只能用日本节点**：它连不上、或被关掉时，插件只用月幕 + VNDB，**照常查作品**，少的是中央值、评分和锐评。代理单独填 `egs.proxy`（留空则跟随「数据源」的 `source.proxy`）；**月幕和 VNDB 一般能直连，不用给它们挂**。
- ⚠️ **按分数筛选靠索引，有没有差别不小**：有那份本地中央值快照时，「按分数查 / 按分数排序」和给资料卡补中央值都走本地，**秒回，低分深处也筛得到**；没有索引时改用**实时扫榜**，口径一样，但要现翻榜单、**慢得多**，而且**只看 `egs.scan_pages`（默认 5）页那一段**。插件内置一份（`seed/egs_index.json.gz`），装完就能用；放超过 `egs.refresh_days`（默认 30 天）会在后台自动增量更新，也可以手动 `/gal update`（增量）或 `/gal sync`（全量重建，管理员）。
- ⚠️ **长文感想可能剧透**：插件优先取无剧透的，并把标记交给模型，但**不保证它不写**；不想用就设 `egs.max_long_reviews = 0`。
- **三个数据源可以分别关**：

  | 关掉 | 会失去 |
  |---|---|
  | `source.ymgal_enabled` | 中文译名、汉化状态、外号检索、中文简介、新作日历 |
  | `source.vndb_enabled` | 通关时长、内容标签、角色与声优、平台 |
  | `source.egs_enabled` | 中央値、好评率、评价维度、长文感想、按分数筛选 |

  三个全关就没法查数据了。
- **贴吧话术默认全部关闭**：要去配置里打开才会学，写进的是麦麦自己的表达方式 / 黑话表。细节见「贴吧话术」一节。
- ⚠️ **插件不读系统代理**（`trust_env=False`），代理只能写在插件配置里。

## 功能特性

> 中文名、日文原名、常用外号都能认；认不出来时按关键词退回搜索。

| 功能 | 示例 |
|---|---|
| 查询资料 | 「近月少女的礼仪有多长」「罚抄好玩吗」「苍彼的声优是谁」 |
| 按条件筛选 | 「推荐批评空间 85 分以上的短篇」「找几部低分作」「75 到 80 分的推理」 |
| 查询新作 | 「最近有什么新 gal」「接下来有什么 gal 要出」 |
| 查询新闻 | 「gal 圈最近有什么新闻」 |
| 锐评 | `/锐评 ランス10` |
| 学习贴吧话术 | `/gal 话术`，默认关闭，见「贴吧话术」一节 |

## 安装

1. 把插件目录整个放进宿主的 `plugins/`。
2. 在 WebUI 的插件页启用。
3. 配置直接在 WebUI 面板里改（也可以编辑插件目录下的 `config.toml`）。

运行数据（批评空间索引、贴吧话术语料留档）落在宿主的 `data/plugins/mizuku003.galgame/`。依赖 `httpx` 已在 `_manifest.json` 里声明，由宿主自动安装。

## 指令

| 指令 | 说明 |
|---|---|
| `/锐评 <作品名>` | 生成一段锐评，依据批评空间的评分与长文感想，不依赖对话上下文；结果包成一条**聊天记录**（合并转发）发出 |
| `/gal <条件>` | 手动筛选，不经过模型 |
| `/gal 类型 <类型>` | 按玩法类型筛选（VN / RPG / SLG / ACT / STG / 3D / 乙女 / BL 等） |
| `/gal 年份 2015` | 查看该年的中央值排行 |
| `/gal 人气` | 按批评空间数据数排行 |
| `/gal` | 发一张用法卡（等同 `/gal help`） |
| `/gal 状态` | 插件状态页：数据源、本地索引、体检（仅管理员） |
| `/gal update` | 增量更新索引（仅管理员） |
| `/gal sync` | 全量重建索引（仅管理员） |
| `/gal random [n]` | 随机抽取 |
| `/gal new [天数]` | 最近已经发售的新作（也可以写 `/gal 新作`） |
| `/gal 预定 [天数]` | 未来准备发售的作品，默认看 `news.upcoming_days` 天 |
| `/gal 情报 [条数]` | 只给圈内新闻 |
| `/gal 详情 <序号>` | 看第 N 条的整篇正文（也可以直接打 `/gal 3`） |
| `/gal help` | 发一张用法卡（排版好读；渲染不出来或关掉 `output.send_card` 时退回同样的文本清单） |
| `/gal 话术 [子命令]` | 贴吧话术学习（默认关闭）。不带子命令看状态；`刷新 [吧名]` 立刻学一轮，`体检` 看实际生效情况，`打标` 按配置补上或去掉吧名标签，`恢复` 把留档的语料写回，`清理` 删掉插件写过的行（连语料一起）（仅管理员） |

### `/gal` 条件语法

方向符置于结尾：`+` 表示以上，`-` 表示以下。

```
/gal 85+           批评空间 85 分以上
/gal 85-90         85~90 分
/gal 60-           60 分以下
/gal 10h           10 小时以内
/gal 10h+          10 小时以上
/gal v80+          改为按 VNDB 评分
/gal t泣系,Mystery  标签
/gal y2015         2015 年（含）之后发售
/gal n5            返回 5 条
/gal 85+ 10h 泣系   条件可叠加，不含运算符的词作为关键词
```

也支持 `键=值` 形式：`/gal egs=85-90 hours=5-20 count=5 sort=egs offset=5`。

几点容易踩的：

- **裸数字按批评空间分数理解**（`10+ 20-` = 中央值 10~20）。筛时长必须加 `h`：`10h+ 20h-` = 10~20 小时。裸数字小于 40 时，回复里会提示这一点。
- **标签用 `t` 前缀**：`tYuri`、`t百合`。常见中文标签已内置别名（百合 / 泣系 / 郁系 / 推理 / 纯爱 / 战斗 / 日常 / 后宫 / 校园 / 短篇 等），其余需用 VNDB 的英文名；标签解析不出来时会在结果里说明。
- **结果默认按人气（票数）排序**。按评分排序传 `sort=egs`（批评空间中央値）或 `sort=vndb`；另有 `sort=length`、`sort=released`、`sort=relevance`（综合质量分）。

### 情报、预定与新作

| 指令 | 只给什么 |
|---|---|
| `/gal 情报 [条数]` | 圈内新闻，不带发售列表 |
| `/gal 预定 [天数]` | 未来准备发售的（月幕日历 + VNDB，带厂商与汉化状态；默认往后看 `news.upcoming_days` 天） |
| `/gal new [天数]`（= `/gal 新作`） | 最近已经发售的（最多回看 50 天） |

每一条都带序号，接着打 `/gal 详情 <序号>`（或直接 `/gal 3`）看详情：详情会再跑一趟原文页抓整篇正文（`news.detail_full` 默认开，超过 `news.detail_chars` 默认 3000 字截断），抓不到就退回 RSS 里那段描述。序号只在列出来之后 30 分钟内有效，重启插件就清空。

- 新闻列表只取标题和摘要，源为 BugBug RSS、同人新闻 dgame 与月幕中文资讯（`news.sources` 里可分别关掉）；待发售来自月幕发售日历与 VNDB，日期精度不同（VNDB 可能只到月份）。
- 日文默认翻成中文（`news.translate`）：新闻标题、作品名、详情正文（900 字分块，某块翻不动就保留那一段日文）；罗马音 / 英文原名不翻。某个源挂了只是少几条，并在末尾说明原因。
- `news.enabled` 关掉后 `/gal 情报`、`/gal 预定` 提示未启用，`/gal new` 仍可用（它只依赖月幕日历），已经列过的那一屏也仍能看详情。

### 用法卡（`/gal help`）

卡片自带一张头图，主色固定暖金（**不受 `output.accent_color` 影响**），宽度跟随 `output.card_width`（默认 830）；渲染不出来、或关掉 `output.send_card` 时自动退回同样的纯文本清单。

想换头图就把图片丢进插件目录的 `assets/help/`：按文件名排序的**第一张**按 `cover` 铺满上半幅（建议横版、宽度 1000px 以上，主体别压在左下角 —— 标题在那儿），后面最多 3 张缩到 172×112 排在卡片底部。自带头图是 `assets/help/` 里的 `zz_builtin_poster.jpg`，你放进去的任何图都会顶替它；把目录清空才改用插件自绘的夜空（纯 SVG，不联网）。

## 配置说明

> 改完保存即生效；贴吧话术那一组默认全关，要用再去打开。

| 配置项 | 说明 |
|---|---|
| `source.proxy` | 三个源共用代理，通常留空（月幕、VNDB 能直连） |
| `source.user_agent` | VNDB 使用条款要求 UA 中包含项目地址 |
| `egs.proxy` | 批评空间专用代理 —— **基本只能用日本节点**，连不上时才需要 |
| `egs.min_votes` | 上榜最低数据数（EGS 的 count 参数），默认 5 |
| `egs.max_pages` | 全量重建的翻页上限 |
| `egs.update_pages` | 增量更新的翻页数，默认 30 |
| `egs.scan_pages` | 索引不可用时实时扫榜的页数 |
| `egs.fetch_long_reviews` / `max_long_reviews` | 是否获取长文感想及条数 |
| `egs.long_review_chars` | 每篇长文感想的截断字数 |
| `review.persona` / `max_chars` | `/锐评` 的口吻与篇幅 |
| `review.prompt` | `/锐评` 的完整提示词，可在配置面板里整段改（见下方说明） |
| `review.model_task` | `/锐评` 使用的模型任务，留空使用宿主默认 |
| `output.send_card` | 是否发送资料卡图片 |
| `recommend.min_vndb_rating` | 默认 VNDB 评分下限，仅在用户未提供评分条件时生效 |
| `style.enabled` / `auto_learn` / `interval_hours` | 贴吧话术的总开关、是否自动学习、间隔小时（前两个默认关） |
| `style.inject_expressions` / `inject_jargons` | 是否让麦麦用学到的表达方式 / 黑话（默认关）。关掉的那一类会从麦麦表里撤出来（语料留档），重新打开自动写回；也决定学习那一轮写哪一类 |
| `style.forums` | 要学的贴吧，默认 `galgame`、`galgame笑话` |
| `style.chat_ids` | 学来的语料写到哪些群；留空则写成全局（默认留空） |
| `style.min_replies` / `max_replies` | 只读回复数落在该区间内的帖子 |
| `style.list_pages` / `posts_per_forum` | 每轮抓几页列表、每个吧最多读几个帖子 |
| `style.target_phrases` | 每个吧目标提炼多少条表达方式 |
| `style.tag_forum` | 把吧名写成 `[galgame吧]` 前缀放进情境，方便在 WebUI 里按吧搜索；关掉后执行 `/gal 话术 打标` 抹掉已有标签 |
| `style.clean_on_disable` | 关闭插件时自动删掉插件写过的行，语料留档，重新打开时写回；默认开 |
| `style.max_floors` / `reply_min_chars` / `reply_max_chars` | 每帖最多读几层、回复层保留的字数区间 |
| `style.delay_seconds` | 抓取间隔（秒），默认 3；贴吧很敏感，别调小 |
| `style.proxy` | 贴吧专用代理，留空跟随「数据源」组的代理 |
| `news.enabled` | 最新情报总开关，关掉后 `/gal 情报`、`/gal 预定` 不可用 |
| `news.sources` | 新闻源，可选 `bugbug`、`dgame`、`ymgal` |
| `news.translate` | 把日文标题、作品名与详情正文翻成中文，翻译失败保留原文 |
| `news.upcoming_days` | `/gal 预定` 默认往后看多少天 |
| `news.per_source` / `max_items` | 每个源最多取几条、一屏最多显示几条 |
| `news.summary_chars` | 列表摘要的截断字数，0 表示不截断 |
| `news.detail_full` | 看详情时是否再跑一趟原文页抓整篇正文，默认开 |
| `news.detail_chars` | 详情正文最多保留多少字，0 表示不限制 |
| `news.cache_minutes` | 抓取结果的缓存分钟数，只在本次运行内有效 |

### 锐评提示词

配置面板「锐评与维护」里的「锐评提示词」（`review.prompt`）就是发给模型的原话，可以整段改，不用碰代码。默认那段是照着「别写出 AI 味」写的：不许编造、别分点、别用「总的来说 / 综上所述 / 作为一款」这类书面语、要说到具体段落。

**提示词里不写素材**：查到的作品素材由插件在末尾自动追加，面板里只留写法要求。会被替换的占位符：

| 占位符 | 含义 |
|---|---|
| `{persona}` | 同分组的「锐评口吻」 |
| `{max_chars}` | 同分组的「篇幅上限」，默认 300 |
| `{material}` | （可选）查到的作品素材，一般不用写，插件会自动补在末尾 |

写错也不会让指令发不出去：漏写 `{material}` 会自动补上素材，认不出的占位符（比如 `{title}`）原样留着，整段清空则回退到内置默认提示词。

## 贴吧话术

> 写进的是麦麦自己的表达方式 / 黑话表；不想留痕就关掉「启用插件」，插件写过的行会自动撤出（语料留档）。

默认全部关闭。先去配置里打开「启用贴吧话术学习」；再打开「自动学习」的话，插件会定期（`style.interval_hours`，默认 24 小时）去指定的贴吧（`style.forums`，默认 galgame、galgame笑话）抓帖子，提炼网友的表达方式与黑话，**写进麦麦自己的表达方式 / 黑话表**，在 WebUI 里管理、审核、导出。只开启用、不开自动学习时，用 `/gal 话术 刷新` 手动跑一轮。写进去的行固定停在「AI 学过」的状态：

| 写入 | 落库状态 | 什么时候会被用上 |
|---|---|---|
| 表达方式 | `checked=false`、`modified_by=AI` | 麦麦开着「仅使用人工精选的表达」时要先在 WebUI 点通过；关着时直接进候选池 |
| 黑话 | `is_jargon=false`，出处写在「证据」里 | 在 WebUI 的「黑话」页勾成黑话 |

会不会被用上由**麦麦自己的设置**决定（`[expression] expression_checked_only`），`/gal 话术 体检` 会读出来告诉你。另外：一个会话里候选表达方式**不足 10 条时一条都不注入**；开了表达方式全局共享，则所有群共用同一批候选。

- **按吧区分**：宿主没给插件留「来源」列，插件把吧名写成情境前缀 —— `[galgame吧] 表示对某事无所谓`，在 WebUI 里搜 `[galgame吧]` 就只看这个吧。不想要前缀，关掉 `style.tag_forum` 再执行 `/gal 话术 打标`。
- **三个开关别混**：关掉「启用插件」→ 自动撤掉插件写过的行（语料留档，重开自动写回，也可手动 `/gal 话术 恢复`）；关掉「注入表达方式」/「注入黑话」→ 只撤那一类，而且之后也不再学那一类；`/gal 话术 清理` → 删行，并把留档的语料一并清掉，不再恢复。两个注入开关都关则整轮跳过，`/gal 话术 状态` 能看到当前状态。
- **清理只删插件自己写的、且没有被你改过的行**（按 id 读回来比对内容指纹）。重启、热重载、关闭机器人都不会触发，只有「关闭插件」才会；插件已经崩掉时残留要手动 `/gal 话术 清理`。
- 贴吧只暴露**回复数**、没有点赞数。抓太频会被「百度安全验证」拦下（403）：插件宁可这一轮不学，立刻停手并冷却 15 分钟，日志写明原因，已学到的语料原样保留。`style.delay_seconds` 默认 3 秒，**不建议调小**；`style.enabled = false` 只停止后续学习，不会动已经写进去的行。

## 数据来源

> 批评空间的中央値与 VNDB 的贝叶斯平均口径不同，不合并为一个分数，在资料卡上并列显示。

| 源 | 提供内容 | 访问方式 |
|---|---|---|
| 月幕 Galgame | 中文译名、有无汉化、外号检索、中文简介、新作日历、即将发售、中文资讯、角色与 CV | OAuth2 公共凭证 |
| VNDB | 通关时长、内容标签、多语言标题、开发商、平台、即将发售、角色与声优 | Kana API，免认证 |
| BugBug | gal 圈新闻的标题、摘要与封面 | RSS，免认证 |
| 批评空间 | 中央値、好评率、积压率、多久开始好看、用户评价维度、短评、长文感想、玩法类型 | 网页抓取 |
| 百度贴吧 | 网友的表达方式与黑话，写进麦麦的表达方式 / 黑话表 | 移动版列表页，免登录 |
